# Heren 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Second part of the site at `/heren1/` for Heren 1 (Clubee stats + live watcher, team stats for all players) with its own Supabase database.

**Architecture:** The code detects the team from `location.pathname`. A team profile supplies name, Supabase URL/key, auth storage key, Clubee data file and feature flags. Routes and navigation respect the flags. Deploy scripts copy the app into `heren1/` and `test/heren1/` with a Heren 1 manifest.

**Tech Stack:** Vanilla JS ES modules, supabase-js (vendored UMD), Postgres RLS, GitHub Pages/Actions, node --test.

**Spec:** docs/superpowers/specs/2026-11-28-heren1-design.md

## Global Constraints
- U16 at `/` and `/test/` must behave exactly as before. Same Supabase project, same session storage key (default), same data file `data/clubee.json`.
- Heren 1 at `/heren1/` and `/test/heren1/`. Supabase session storage key `sb-heren1`. Data file `data/clubee-heren1.json`.
- Heren 1 features ON: Clubee import, matches, kalender, live watcher, stats, accounts, ploegstats. OFF: rapporten/zelfevaluatie, XP/badges/avatar, trainingen/aanwezigheid, schiettraining, playbook, opstelling/voorbereiding, vaardigheden.
- Heren 1 players must never see teammates' e-mail addresses.
- Every interpolated user text goes through `esc()`.
- Live publish only after "publiceer maar".

## Review Focus
1. A Heren 1 player opening a U16-only route by typing the URL (e.g. `#/mijn`, `#/schieten`) → lands on Home, no error.
2. Heren 1 not configured yet (placeholder URL) → clear "nog niet ingesteld" screen, U16 unaffected.
3. Being logged in to U16 and then opening `/heren1/` → not logged in there (separate session), and the reverse.
4. Test copy `/test/heren1/` → recognised as Heren 1 AND as test (trainers only).
5. Clubee config for Heren 1 missing/empty → scraper skips it without failing the U16 run.
